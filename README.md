# nids-service

**NIDS-service** — учебный сервис обнаружения сетевых вторжений (Network Intrusion
Detection System) со сквозным жизненным циклом разработки.

## Назначение

Сервис принимает по HTTP вектор признаков сетевого соединения (протокол, длительность
соединения, число пакетов и байт в прямом и обратном направлении, число неудачных
попыток входа и т. п.) и возвращает оценку вероятности того, что соединение является
атакой, а также метку класса трафика. Модель обучается на датасете сетевого трафика
и поставляется в сервис как артефакт `model.pkl`.
